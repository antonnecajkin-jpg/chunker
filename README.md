# Chunker

Разбивает DataFrame на чанки по указанной колонке.

## Установка

pip install -r requirements.txt

## Запуск тестов

pytest test_chunker.py -v

## Использование

from chunker import split_into_chunks

# Данные не упорядочены, функция сортирует сама
chunks = list(split_into_chunks(df, chunk_size=4))

# Данные упорядочены, можно сэкономить на сортировке
chunks = list(split_into_chunks(df, chunk_size=4, assume_sorted=True))

# Другая колонка
chunks = list(split_into_chunks(df, chunk_size=4, column="event_type"))

## Возврат

Функция возвращает генератор. Для получения списка используйте list().

## Требования

1. Все чанки, кроме последнего, >= chunk_size.
2. Последний чанк может быть меньше chunk_size.
3. Все вхождения одного значения колонки в одном чанке.
4. Значения между чанками не пересекаются.
5. Порядок сохраняется после сортировки.

## Параметры

* df: DataFrame.
* chunk_size: желаемый минимальный размер чанка.
* column: имя колонки для группировки. По умолчанию "dt".
* assume_sorted: если True, данные считаются упорядоченными по column. Если нет, выбрасывается ValueError. По умолчанию False, данные сортируются внутри.

## Исключения

* ValueError: если chunk_size <= 0.
* ValueError: если assume_sorted=True, но данные не упорядочены.
* ValueError: если column содержит NA (pd.NA, NaN, NaT).
* KeyError: если column отсутствует в df.

## Ограничения

Колонка не должна содержать пропуски (pd.NA, NaN, NaT). При наличии пропусков выбрасывается ValueError. Перед вызовом используйте fillna() или dropna().

## Тесты

27 тестов:

* обычный случай;
* границы: chunk_size = 1, chunk_size > len(df), пустой df, одна группа, одна большая группа;
* ошибки: chunk_size <= 0, неупорядоченные данные при assume_sorted=True, отсутствующая колонка;
* реальные данные: неравные группы, неупорядоченные данные;
* произвольные колонки;
* пример из ТЗ;
* пропуски: pd.NA, NaN, NaT;
* стабильность сортировки;
* инварианты: данные сохранены, группы не разорваны.

## Про хвостовой чанк

Хвостовой чанк это последний. Он может быть меньше chunk_size, если группа не влезает целиком.
