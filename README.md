# Chunker

Разбивает DataFrame на чанки по указанной колонке.

## Установка

pip install -r requirements.txt

## Запуск тестов

pytest test_chunker.py -v

## Использование

from chunker import split_into_chunks

# Данные не упорядочены — функция отсортирует сама
chunks = split_into_chunks(df, chunk_size=4)

# Данные упорядочены — можно сэкономить на сортировке
chunks = split_into_chunks(df, chunk_size=4, assume_sorted=True)

# Другая колонка
chunks = split_into_chunks(df, chunk_size=4, column="event_type")

## Требования

- Размер каждого чанка >= chunk_size
- Все вхождения одного значения колонки в одном чанке
- Значения между чанками не пересекаются
- Порядок сохранён

## Параметры

- `df` — DataFrame.
- `chunk_size` — желаемый минимальный размер чанка.
- `column` — имя колонки для группировки (по умолчанию `"dt"`).
- `assume_sorted` — если `True`, предполагается, что `df` уже упорядочен по `column`. Если данные НЕ упорядочены — выбрасывается `ValueError`. Если `False` (по умолчанию) — данные сортируются внутри функции.

## Исключения

- `ValueError` — если `chunk_size <= 0`.
- `ValueError` — если `assume_sorted=True`, но данные не упорядочены.
- `KeyError` — если `column` отсутствует в `df`.

## Тесты

16 тестов покрывают:
- Обычный случай.
- Граничные случаи (`chunk_size = 1`, `chunk_size > len(df)`, пустой df, одна группа, одна большая группа).
- Ошибки (`chunk_size <= 0`, неупорядоченные данные при `assume_sorted=True`, отсутствующая колонка).
- Реальные данные (неравные группы, неупорядоченные данные).
- Произвольные колонки.
- Инварианты (данные сохранены, группы не разорваны).
